# Server (Node.js)
1. Install Node.js 18+ from nodejs.org
2. In this folder run:  npm install
3. Then run:           npm start
4. Open http://localhost:3000/health  -> {"ok":true}
5. Open http://localhost:3000/?token=b285978f6328b95d415114030be8c4f4  -> Start camera
Do NOT upload the .env file to GitHub (the .gitignore already blocks it).
